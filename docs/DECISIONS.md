# 判断記録

- 2026-10-08 M1: 静音時間は開始を含み終了を含まない区間（22:00 は静音、8:00 は通知可）。開始>終了なら日跨ぎ、開始==終了は静音なし。注入した Calendar のタイムゾーンで判定する。
- 2026-10-08 M1: 1日上限は、注入した Calendar で now と同じ日の通知履歴を場所を問わず数える。
- 2026-10-08 M1: クールダウンは lastNotifiedAt と、履歴中のその場所の最新通知のうち新しい方から数え、ちょうど7日経過で通知対象に戻す。
- 2026-10-08 M1: snoozedUntil > now の場所を除外する（== now は対象）。「今日はやめる」は now より後で最初に静音が明ける時刻（既定 次の8:00）まで、静音なしの設定なら翌日0時まで。「あとで」は既定3時間。
- 2026-10-08 M1: 優先度スコア = 距離 − min(経過日数, 30) × 5m（小さいほど優先、古さボーナスは最大150m）。同点は距離 → id.uuidString の昇順。
- 2026-10-08 M1: 通知距離は境界を含む（500m ちょうどは対象）。徒歩分数は 80m/分で切り上げ、最小1分。
- 2026-10-08 M1: 営業時間の曜日は 1=日〜7=土。開店を含み閉店を含まない。閉店<開店は翌日への日跨ぎ（土→日も含む）、開店==閉店は終日営業。未入力・空は営業中扱い。
- 2026-10-08 M1: 通知 title は「近くにあるよ」「ちょっと寄れそう」「そういえば、ここ」「いま行けそうだよ」の4種。
- 2026-10-08 M1: Place は Foundation のみの値型にする。SwiftData の永続化モデルは M2 で追加する。AnosaKit は swift test をホスト（macOS 26+）で回すため macOS platform も宣言する。
- 2026-10-08 M1: Info.plist は XcodeGen の info: で生成し、生成物もコミットする。編集の正本は project.yml。
- 2026-10-08 M1: 位置情報の利用目的文言は仮文面とする（M3 で見直し可）。
- 2026-10-08 M1: iOS アプリは iPhone 専用（TARGETED_DEVICE_FAMILY=1）。
- 2026-10-08 M1: Share Extension の受け取り対象は Web URL 1件とテキスト。処理の中身は M2 で実装する。
- 2026-10-08 M1: App Group / entitlements は M1 では追加しない（App Group ID は手動作業で、必要になる M3 以降に追加）。
- 2026-10-08 M1: シミュレータ向けビルドは -sdk ではなく generic destination（scripts/ci/build-scheme.sh）で行う。-sdk iphonesimulator では Anosa に埋め込まれた Watch ターゲットまで iOS SDK でビルドされて失敗し、verify.conf の argv には空白を含む -destination を書けないため。デバイス名を指定しないので Xcode 26（CI）/ 27（手元）で同じコマンドが動き、worktree 間のシミュレータ衝突もない。
- 2026-10-08 M1: AnosaKit のテストは swift test でホスト実行し、シミュレータ名を指定しない（手元の simctl では iOS 27 の iPhone 17 などが実在するが、検証コマンドはどのデバイス名にも依存させない）。
- 2026-10-08 M1: xcodebuild -list に出る AnosaKit スキームはローカルパッケージから自動生成されるもの。ビルド対象スキームは5つとし、パッケージは swift test と各ターゲットのビルドで検証する。
