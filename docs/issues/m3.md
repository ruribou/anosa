## 概要
docs/SPEC.md の「位置情報とバックグラウンド動作」「通知」に従い、アプリを開かなくても通知が届くようにする。先に docs/SPEC.md と CLAUDE.md を読むこと。前提: M1がmainにマージ済み。

## やること
- 権限の2段階フロー（使用中のみ → 説明のうえ「常に許可」へ誘導）
- significant-location-change とリージョンモニタリングの併用（近い場所のみ登録して入れ替え）
- 位置変化のたびに判断エンジンを実行し、該当すればローカル通知
- 通知アクション: 行ってみる（Appleマップで徒歩ルート）/ 今日はやめる / もう行った
- 現在地と近い場所のスナップショットを App Group に保存

## 受け入れ条件
- [ ] 全スキームがビルド成功する
- [ ] リージョン入れ替えロジックのテストが通る
- [ ] xcrun simctl location での位置変更手順を README に書き、通知が届くことを確認した記録を会話に残している
- [ ] 通知アクションが状態更新（スヌーズ・履歴化）につながっている
