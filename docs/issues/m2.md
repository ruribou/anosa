## 概要
docs/SPEC.md の「保存」「iOSアプリ本体」に従い、場所を最小の手数で保存できるようにする。先に docs/SPEC.md と CLAUDE.md を読むこと。前提: M1がmainにマージ済み。

## やること
- Share Extension: URL/テキストから MKLocalSearch で場所を解決して保存（解決できなければ最小の候補選択UI）
- アプリ内の手動追加（検索 → 保存）
- 保存後は「保存したよ。あとは忘れていいよ」の一言のみ表示して即閉じる
- 保存済みの一覧（行きたい / 行った / アーカイブ）。管理画面は凝らない
- App Intent「Anosaに保存」の骨組み

## 受け入れ条件
- [ ] 全スキームがビルド成功する
- [ ] 保存・取得・ステータス変更のテストが通る
- [ ] Liquid Glass方針（標準コンポーネント優先、独自背景を重ねない）に沿っている
- [ ] ビルド・テストの出力を会話に残している
