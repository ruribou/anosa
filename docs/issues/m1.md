## 概要
docs/SPEC.md の「ターゲット構成」「判断エンジン」「通知」「データモデル」に従い、土台とコアロジックを作る。先に docs/SPEC.md と CLAUDE.md を読むこと。

## やること
- XcodeGen（project.yml）で全ターゲットの骨組みを生成（deploymentTarget: iOS 26.0 / watchOS 26.0）
- AnosaKit: Place モデル、判断エンジン（純粋関数）、設定構造体、OpeningHoursProvider（プロトコル＋スタブ）、通知文言（1ファイル）
- docs/PLAN.md を作成（主要な型・構成）

## 受け入れ条件
- [ ] xcodegen generate が成功する
- [ ] 全スキームが xcodebuild でシミュレータ向けにビルド成功する
- [ ] AnosaKit のユニットテストが通る（距離・クールダウン・1日上限・静音時間・スヌーズ・優先度）
- [ ] ビルド・テストの出力を会話に残している

## 追加の受け入れ条件（CI・検証）
- [ ] .claude/verify.conf.example を参考に .claude/verify.conf を作成し、xcodegen generate、全スキームのシミュレータ向けビルド、AnosaKit のユニットテストを check として明示している
- [ ] .claude/scripts/verify run が PASS する
- [ ] .github/workflows/ci.yml の検証ステップが verify run（動かない場合は同等の xcodebuild コマンド）を実行し、PRのCIが green になる
- [ ] シミュレータ名は xcrun simctl list で実在を確認して指定し、CI（macos-26）と手元で同じコマンドが動く
